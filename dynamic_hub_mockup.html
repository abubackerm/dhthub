Developer Reference Guide — Dynamic Hub B2B Platform

🎨 Color System

#0A1628
Primary Navy

#112240
Mid Navy

#F5620F
Orange CTA

#8A9BB8
Steel Text

#F4F6FA
Light Text

  • Navy = background, trust, industrial feel
  • Orange = all CTAs, highlights, active states
  • Steel gray = secondary text, specs, labels
  • White/light = headings, product names
  • Green #2ECC71 = in-stock indicator only

📝 Typography

  • Headings: Barlow Condensed 700/800 — bold, industrial, compact
  • Body/UI: Barlow 400/500/600 — readable, modern
  • Page titles: 32–48px Barlow Condensed 800
  • Product names: 17px Barlow Condensed 700
  • Specs / Labels: 11–12px Barlow 400 in steel color
  • Buttons: 12–14px Barlow Condensed 700 uppercase
  • Arabic support: Noto Kufi Arabic (same weight feel)

🖥️ Page Structure

  • Top bar → Navbar (sticky) → Hero+Search → Trust bar
  • Categories grid (12 cards, 6-col desktop, 2-col mobile)
  • Quick Access cards (Excel BOM, Approved Items, AVL)
  • Catalogue: Left filter sidebar (240px) + Product grid (3-col)
  • Product detail: full-width image, specs table, quote CTA
  • Floating WhatsApp button (bottom-right, always visible)
  • Footer: 4-column with certs and company info

⚡ B2B Features Required

  • Company account + contractor approval workflow
  • RFQ basket (not direct checkout) — Add to Quote model
  • Quote submitted → DH team reviews → sends formal quotation
  • Excel BOM upload → auto-match to catalogue → bulk quote
  • ✅ Approved tick per product — company-specific saved lists
  • Aramco AVL / 9COM filter — critical for contractors
  • Order history + repeat order in one click
  • Credit account / NET30 payment term support

📱 Mobile & Performance

  • Breakpoints: 1200 / 768 / 480px
  • Category grid: 6-col → 3-col → 2-col
  • Product grid: 3-col → 2-col → 1-col
  • Sidebar: collapsible drawer on mobile (filter button)
  • Target page load: under 2 seconds (contractors on site)
  • Lazy-load product images, skeleton loading states
  • WhatsApp button always visible on mobile — primary CTA
  • Sticky navbar stays visible while scrolling

🔌 Tech & Integration

  • Recommended stack: Laravel (backend) + Vue.js or React (frontend)
  • Or: Magento 2 / WooCommerce (B2B extension) for faster launch
  • Product import: Excel/CSV bulk upload with SKU mapping
  • Search: Algolia or Meilisearch for instant part-number search
  • WhatsApp: WATI.io or Twilio WhatsApp Business API
  • Payment: SADAD, bank transfer, credit account invoice
  • Language: Arabic/English toggle (RTL support required)
  • SSL, HTTPS, Saudi data residency if required
⚠️ Critical Developer Notes

1. No direct checkout by default. This is a B2B quote-first business. All products go into a "Quote Basket", not a shopping cart.
2. User onboarding = company registration. Individual users register under a Company Account (contractor name, CR number, Aramco contractor ID).
3. Product specs are critical. Every product MUST have: part number, full spec table, datasheet PDF download, brand, compliance standards.

4. Approved Tick = company-level bookmark. When a user ticks ✅ a product, it saves to their company's Approved Items list — shared across all users from that company.
5. Arabic is not optional. Eastern Province contractors expect Arabic. Product names + navigation + checkout must be fully translated (RTL layout).
6. Orange = action only. Never use orange for decorative purposes. It signals "click here" to users.
